# Excel导入功能说明

## 功能概述

系统支持通过Excel文件批量导入成品和配件信息，包括产品名称、配件关系，以及按Excel中的库存数量覆盖系统库存。

## 使用方法

### 1. 准备Excel文件

Excel文件格式要求：
- 文件格式：`.xlsx` 或 `.xls`
- 文件大小：不超过10MB
- 可以包含多个工作表

### 2. Excel格式示例

```
| 产品名称 | 库存数量 | 配件   | 库存数量 |     | 产品名称 | 配件   |
|---------|---------|-------|---------|-----|---------|-------|
| 成品A   | 100     | 配件1 | 80      |     | 成品B   | 配件2 |
|         |         | 配件2 |         |     |         | 配件3 |
|         |         | 配件3 | 50      |     |         | 配件4 |
```

格式说明：
- 支持 `产品名称 + 配件` 格式
- 也支持 `产品名称 + 库存数量 + 配件 + 库存数量` 格式（如 `成品和配件.xlsx` 的 `F11`）
- 后续行为该产品所需的配件
- 每组产品之间用空列分隔
- 可以在同一工作表中包含多组产品
- 库存数量单元格有值时会覆盖系统库存，留空则不覆盖

### 3. 导入步骤

1. 登录系统（需要管理员或仓库管理员权限）
2. 进入"当前库存"页面
3. 点击页面右上角的"导入Excel"按钮
4. 选择准备好的Excel文件
5. 确认导入信息
6. 等待导入完成

### 4. 导入结果

导入完成后，系统会显示：
- 新增配件数量
- 跳过的已存在配件数量
- 新增成品数量
- 跳过的已存在成品数量
- 建立的配件关系数量
- 覆盖库存的数量

### 5. 注意事项

- 只有管理员（ADMIN）和仓库管理员（MANAGER）可以导入数据
- 如果产品名称已存在，将跳过该产品的创建，但会尝试添加配件关系
- 如果Excel中填写了库存数量，系统中的库存会被直接替换为该值
- 如果Excel中的库存数量为空，则保留系统原库存不变
- 未填写库存数量的新产品初始库存仍为0
- 导入的产品单位默认为"个"
- 每个配件的默认数量为1

## 权限要求

- 需要管理员（ADMIN）或仓库管理员（MANAGER）角色
- 普通员工（WORKER）无法使用导入功能

## 技术说明

### 后端API

- 接口：`POST /api/products/import`
- 权限：需要 `@admin_required` 装饰器
- 参数：`file` - Excel文件（multipart/form-data）
- 返回：导入统计信息

### 前端实现

- 位置：库存管理页面（InventoryView.vue）
- 组件：使用 Ant Design Vue 的 Upload 组件
- 文件验证：类型和大小检查
- 用户确认：导入前弹出确认对话框
